# 方法与方法集

方法是带接收者的函数。接收者仍按值传递：值接收者得到副本，指针接收者得到地址副本并可修改原值。

## 接收者选择

- 方法需要修改接收者时使用 `*T`。
- 大结构体或包含 `sync.Mutex` 等不可复制状态时使用 `*T`。
- 小型、不可变的值类型可使用 `T`。
- 同一类型的方法接收者应尽量保持一致。

## 方法集

- `T` 的方法集只包含接收者为 `T` 的方法。
- `*T` 的方法集包含接收者为 `T` 和 `*T` 的方法。

编译器可以为可寻址变量的普通方法调用自动取地址，但接口实现依据方法集判断，不会进行这一步隐式转换。因此，如果接口所需方法使用 `*T` 接收者，通常只有 `*T` 实现该接口。
