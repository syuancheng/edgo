# 函数与闭包

Go 的参数始终按值传递。传入指针、slice、map、channel 或 function 时，复制的是对应的值；它们可能继续引用同一底层数据。

## 函数值

函数可以赋给变量、作为参数、作为返回值或存入结构体。函数值只能与 `nil` 比较。

## 可变参数

`func sum(values ...int)` 中的 `values` 是 `[]int`。传入现有切片时使用 `sum(values...)`。

## 闭包

闭包会捕获其引用的外层变量。变量可能逃逸到堆，但这是编译器根据生命周期作出的实现决定。循环中需要每次迭代独立值时，显式创建局部副本，可兼容不同 Go 版本的循环变量语义。

## `defer`

注册 `defer` 时会立即计算函数值和参数；闭包体内直接引用的外部变量则在延迟函数真正执行时读取。多个 `defer` 按后进先出顺序执行。
