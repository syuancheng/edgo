# Go 语言核心

本目录按语言概念组织。每个主题至少包含一个可运行示例；进入任一目录后可执行 `go run .`，测试型主题使用 `go test -v`。

- 基础：[`variables`](./variables/)、[`strings`](./strings/)、[`maps`](./maps/)
- 抽象：[`functions`](./functions/)、[`methods`](./methods/)、[`value-semantics`](./value-semantics/)
- 健壮性：[`errors`](./errors/)、[`generics`](./generics/)、[`testing`](./testing/)
- 并发：[`concurrency`](./concurrency/)
- 互操作：[`cgo`](./cgo/)
